# 🚀 Generative AI Usage Intelligence Project

## 📌 Overview

The **Generative AI Usage Intelligence Project** is a data analytics and machine learning project designed to analyze AI tool usage patterns and measure productivity improvements across different departments and task categories.

This project focuses on understanding how Generative AI tools impact efficiency, task completion, and time savings using data-driven insights and visual analytics.

---

## 🎯 Objectives

* Analyze Generative AI adoption trends
* Measure productivity gain using AI tools
* Visualize department-wise AI usage
* Perform data preprocessing and analytics
* Build an ML-ready analytical workflow

## 📈 Productivity Gain Formula

Productivity gain was calculated using:

```python
productivity_gain = manual_time_estimate_minutes - time_spent_minutes
```

This helps evaluate the efficiency improvement achieved through Generative AI tools.
